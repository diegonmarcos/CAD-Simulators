# OpenCAD

Subfolder of Structural-Designer.

## Brief

Agentic parametric CAD over MCP. Pinned submodules: `freecad-mcp` (FreeCAD) and `autocad-mcp` (AutoCAD LT or headless DXF via ezdxf). See the repo README for upstream, stars and licences.

## FOSS references

Existence of each repository checked with `git ls-remote` on 2026-10-29. Licences as published upstream; re-check before reuse.

- [FreeCAD/FreeCAD](https://github.com/FreeCAD/FreeCAD): Parametric 3D CAD modeller (LGPL-2.1+)
- [CadQuery/cadquery](https://github.com/CadQuery/cadquery): Python parametric CAD scripting (Apache-2.0)
- [gumyr/build123d](https://github.com/gumyr/build123d): Python BREP CAD (Apache-2.0)
- [LibreCAD/LibreCAD](https://github.com/LibreCAD/LibreCAD): 2D CAD (GPL-2.0)
- [openscad/openscad](https://github.com/openscad/openscad): Script-based solid modeller (GPL-2.0+)
- [solvespace/solvespace](https://github.com/solvespace/solvespace): Parametric 2D/3D CAD (GPL-3.0)
- [Open-Cascade-SAS/OCCT](https://github.com/Open-Cascade-SAS/OCCT): Open CASCADE geometry kernel (LGPL-2.1)
