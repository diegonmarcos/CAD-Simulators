# Simulators

Master folder of the Simulators line.

## Brief

Simulation and visual/3D tools: `blender-mcp` (pinned submodule; general 3D/visual modelling, so placed here rather than in OpenCAD) and `sailytics` (in-repo sailing simulator code). Physics and CFD engines are planned.

## FOSS references

Existence of each repository checked with `git ls-remote` on 2026-10-29. Licences as published upstream; re-check before reuse.

- [OpenFOAM/OpenFOAM-dev](https://github.com/OpenFOAM/OpenFOAM-dev): CFD toolbox (GPL-3.0)
- [projectchrono/chrono](https://github.com/projectchrono/chrono): Multi-physics and vehicle dynamics (BSD-3-Clause)
- [google-deepmind/mujoco](https://github.com/google-deepmind/mujoco): Rigid-body physics simulator (Apache-2.0)
- [ElmerCSC/elmerfem](https://github.com/ElmerCSC/elmerfem): Multiphysics finite element software (GPL-2.0+)
- [su2code/SU2](https://github.com/su2code/SU2): CFD and design optimisation suite (LGPL-2.1)
- [dealii/dealii](https://github.com/dealii/dealii): Finite element library (LGPL-2.1+)
- [bulletphysics/bullet3](https://github.com/bulletphysics/bullet3): Real-time physics engine (Zlib)
- [gazebosim/gz-sim](https://github.com/gazebosim/gz-sim): Robotics simulator (Apache-2.0)
