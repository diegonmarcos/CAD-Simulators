# OpenRevit

Subfolder of Structural-Designer.

## Brief

Scope: Revit-like parametric BIM authoring (walls, floors, families, schedules, views) driven by an agent.

MCP candidates (repositories exist, checked with `git ls-remote`; stars, licence file and recent activity not yet reviewed, so nothing is pinned): [mcp-servers-for-revit/mcp-servers-for-revit](https://github.com/mcp-servers-for-revit/mcp-servers-for-revit) and [revit-mcp/revit-mcp-plugin](https://github.com/revit-mcp/revit-mcp-plugin), both drive Autodesk Revit (Windows). Pin one as a submodule after that review.

## FOSS references

Existence of each repository checked with `git ls-remote` on 2026-10-29. Licences as published upstream; re-check before reuse.

- [IfcOpenShell/IfcOpenShell](https://github.com/IfcOpenShell/IfcOpenShell): IFC library; also hosts Bonsai (BlenderBIM) (LGPL-3.0)
- [ThatOpen/engine_web-ifc](https://github.com/ThatOpen/engine_web-ifc): IFC parser for the web (MPL-2.0)
- [ThatOpen/engine_components](https://github.com/ThatOpen/engine_components): That Open Engine BIM components (MIT)
- [ThatOpen/engine_ui-components](https://github.com/ThatOpen/engine_ui-components): That Open Engine UI components (MIT)
- [xeokit/xeokit-sdk](https://github.com/xeokit/xeokit-sdk): Web BIM/CAD model viewer SDK (AGPL-3.0)
- [opensourceBIM/BIMserver](https://github.com/opensourceBIM/BIMserver): Open-source BIM model server (AGPL-3.0)
- [FreeCAD/FreeCAD](https://github.com/FreeCAD/FreeCAD): FreeCAD with BIM workbench (LGPL-2.1+)
